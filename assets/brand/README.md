# Coyote brand assets

| File | What it is |
|------|------------|
| `cayote-logo-showcase.png` | The supplied logo sheet, **unmodified** (byte-identical to the file provided). Contains the primary lockup (coyote mark + wordmark, **which still reads "Cayote": the project was renamed to Coyote after this image was supplied, and the image has deliberately not been edited**) and three app-icon variants: dark tile, bare mark on dark, and light-gradient tile with dark mark. |

Usage rules:

* Do not redraw, recolor, crop, or regenerate the logo. Use the supplied file as is.
* The sheet is on a near-black background, so it is shown on dark or as-is, never on top of
  other imagery.
* Individual cropped/transparent/vector variants (SVG, favicon, per-size icons) have **not** been
  supplied. When they are, add them here and list them in the table above.

The app icons used by Coyote Studio (`studio/build/icon.*`, `studio/renderer/logo.png`) are derived from the mark only, not from the wordmark. Supply a corrected logo sheet to replace the file above.
